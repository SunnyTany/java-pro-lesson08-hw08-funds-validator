# 🏦 Bank Account Console App

Простое консольное Java-приложение для управления банковским счетом. 

Проект демонстрирует принципы объектно-ориентированного программирования (ООП), кастомную обработку исключений и валидацию пользовательского ввода.

## 🚀 Функционал

- Управление балансом: Хранение и расчет остатка средств на счету.
- Валидация транзакций:Проверка на достаточность средств (Custom Checked Exception).
- Защита от ввода отрицательных сумм или нуля.Обработка некорректного ввода (буквы вместо цифр).
- Интерактивный режим: Бесконечный цикл операций с возможностью выхода через команду exit.

## 🛠 Технологии

- Язык: Java 17+
- Парадигма: ООП (Инкапсуляция, разделение логики модели и интерфейса).
- Обработка ошибок: Использование try-catch блоков и собственных классов исключений.

## 📂 Структура проекта

- app/Account.java — Класс модели счета. Содержит логику списания и хранения баланса.
- app/FundsException.java — Кастомное исключение для обработки ошибок бизнес-логики.
- app/Main.java — Точка входа. Реализует пользовательский интерфейс и цикл взаимодействия.

## 💻 Примеры работы

Успешная покупка:

textBalance is USD 1000.00.
Enter purchase amount, USD: 250
Funds are OK. Purchase paid.
Balance is USD 750.00

Недостаточно средств:

textBalance is USD 1000.00.
Enter purchase amount, USD: 1200
Insufficient funds!

Некорректный ввод:

textEnter purchase amount, USD: abc
Error: Please enter a valid number or 'exit'.
